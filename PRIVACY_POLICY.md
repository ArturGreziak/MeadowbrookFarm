## Local game data
The game stores farm progress and settings locally on your device. No account or developer-operated cloud save is included. Reset Progress replaces local progress after confirmation. Uninstalling the Android application or clearing its storage removes local data; clearing browser site data removes the Web save. The Android build disables application backup.

## Advertising in the Android version
The Android version integrates Google Mobile Ads and Google's User Messaging Platform. Depending on configuration and consent, Google may process device and advertising identifiers, IP address, approximate location derived from network information, diagnostics and interactions with advertisements. The developer must verify the current SDK disclosures, actual settings, recipients, retention and applicable legal basis before publishing this policy. Development builds use official test advertising IDs.

Where required, a consent form is displayed and Privacy options is available from the menu. Advertising requests are gated by the consent SDK. Optional rewarded ads provide energy only following the SDK reward callback. Offline farming does not depend on advertisements.
